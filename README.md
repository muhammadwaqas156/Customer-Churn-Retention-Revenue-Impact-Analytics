# 📊 Customer Churn, Retention & Revenue Impact Analytics

## 🚀 Project Overview

Customer churn is one of the most critical challenges for subscription-driven businesses.
This end-to-end business analytics project provides a complete multi-page dashboard solution to analyze customer churn, retention behavior, revenue impact, and risk levels.

The project delivers a **customer lifecycle intelligence system** through four interconnected dashboards.

### 🔍 Key Focus Areas

* Churn drivers
* Customer behavior patterns
* Revenue loss
* Retention risk
* Engagement trends

### 🛠️ Tools & Technologies

* Excel Data Model / Power Pivot
* Power BI-style dashboard design
* SQL 

---

## 🧩 Dashboard Pages

## 📈 Key Insights

* Low engagement and high support ticket volume strongly correlate with churn
* High-risk customers contribute disproportionately to churned revenue
* Tenure is a major predictor — early-stage customers churn more frequently
* Revenue loss is concentrated in Premium and Standard subscription tiers
* Inactive login behavior is a strong churn indicator
